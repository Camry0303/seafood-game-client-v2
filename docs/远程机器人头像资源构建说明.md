# 远程机器人头像资源构建说明

本文档说明机器人（bot）头像的远程资源构建与部署方式，供热更新（HotUpdate）服务器运维/构建人员参考。

## 1. 背景

客户端在 `RemoteSpriteFrameLoader.getAvatarSpriteFrame` 中，对以 `bot_` 开头的头像标识，
会从**热更新域名**下按固定路径远程加载 JPEG 图片（与微信头像远程加载机制一致）：

- 头像标识示例：`bot_avatar_000`、`bot_avatar_001` ...
- 远程资源地址规则：

```
https://{热更域名}/avatars/{头像标识}.jpeg
```

示例（假设热更域名为 `https://hotupdate.example.com`）：

```
https://hotupdate.example.com/avatars/bot_avatar_000.jpeg
https://hotupdate.example.com/avatars/bot_avatar_001.jpeg
```

> 注意：
> - 路径段为复数 **`/avatars/`**。
> - URL 中的文件名**保留** `bot_` 前缀（即 `{头像标识}` 原样拼接，不要去掉前缀）。
> - 文件扩展名为小写 **`.jpeg`**。

## 2. 客户端地址来源

热更域名由客户端从 `ServerConfig.gateway_server_url` 派生得到，规则：
- 将 `gateway` 替换为 `hotupdate`；
- 将协议 `http:` 升级为 `https:`（localhost 除外）。

因此部署时，请保证热更服务器的 `avatars` 目录可通过 **HTTPS** 被客户端访问。

## 3. 构建与部署步骤

1. 在项目根目录找到资源包 `bot-avatars.zip`。
   - 内部文件命名格式为 `bot_avatar_xxx.jpeg`（xxx 为 3 位零填充数字，从 `000` 起）。
2. 将 `bot-avatars.zip` **解压**到热更新服务器的**根目录下的 `avatars` 文件夹**中。

   目录结构示意（热更服务器根目录）：

   ```
   <热更服务器根目录>/
   └── avatars/
       ├── bot_avatar_000.jpeg
       ├── bot_avatar_001.jpeg
       ├── bot_avatar_002.jpeg
       └── ... （其余 bot_avatar_xxx.jpeg）
   ```

3. 确认通过浏览器/HTTP 客户端能正常访问：

   ```
   https://{热更域名}/avatars/bot_avatar_000.jpeg
   ```

   返回 200 且为有效 JPEG 图片即部署成功。

## 4. 回退与兜底

- 若热更域名未配置（为空），或远程图片加载失败，客户端会自动回退到本地默认头像
  `Images/Common/default_avatar_01`，不会崩溃。
- 新增 bot 头像时：将新文件按 `bot_avatar_xxx.jpeg` 命名加入 `avatars` 目录即可，无需改客户端代码。

## 5. 相关客户端代码

`assets/Scripts/Utils/RemoteSpriteFrameLoader.ts` 的 `getAvatarSpriteFrame` 中 `bot_` 分支：

```ts
if (url.startsWith("bot_")) {
  const domain = GlobalData.Instance.getHotUpdateDomain();
  if (domain) {
    const botUrl = `${domain}/avatars/${url}.jpeg`;
    const spriteFrame = await wechatSpriteFrameLoader(botUrl);
    if (spriteFrame) {
      return spriteFrame;
    }
  }
  // 域名缺失或加载失败时回退默认头像
  return ResourceManager.Instance.getSpriteFrame("Images", `Common/default_avatar_01`);
}
```
